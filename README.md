# PAC-MAN Clone

HTML + CSS + JavaScript だけで動く、外部アセット不使用・単一ファイル完結のパックマンクローンです。Canvas 2D で迷路とキャラクターを描画し、WebAudio でその場生成する効果音を鳴らします。

## 遊び方

- **PC**: 矢印キー または WASD で移動、SPACE でスタート/ポーズ、R でリスタート
- **スマホ**: 画面のスワイプ / 十字ボタンで移動、タップでスタート/ポーズ、⟳ ボタンでリスタート

パワーエサを取るとゴーストがイジケ状態になり、食べると 200 → 400 → 800 → 1600 点のコンボ得点が入ります。

## 実装のポイント

- 28×31 タイルの迷路を Canvas 上に自動生成し、通路側だけに輪郭線を描く原作方式
- Blinky・Pinky・Inky・Clyde それぞれ異なるターゲットタイルを狙う追跡ロジック
- スキャッター/チェイスの時間帯切り替え、ワープトンネル、レベルアップによる難易度上昇
- ハイスコアを `localStorage` に保存

## 遊ぶには

`index.html` をブラウザで開くだけで動作します。GitHub Pages を有効化すれば、そのままブラウザからプレイできます。
