# PAC-MAN Clone

HTML + CSS + JavaScript だけで動く、外部アセット不使用・単一ファイル完結のパックマンクローンです。Canvas 2D で迷路とキャラクターを描画し、WebAudio でその場生成する効果音を鳴らします。

## 遊び方

- **PC**: 矢印キー / WASD で移動、SPACE でスタート/ポーズ、P でポーズ、R でリスタート、M でミュート
- **スマホ**: 盤面をスワイプして移動（指を動かした瞬間に反応し、連続スワイプも可）、タップでスタート/ポーズ、十字ボタンと ⟳ ボタンも利用可能。縦向き・横向きの両方に最適化（横向きでは盤面の右側に情報と十字ボタンを配置）。プレイ中は画面が暗くならない

## ゲーム内容

- **難易度選択**（タイトル / ゲームオーバー画面のボタン、または 1 / 2 / 3 キー）。残機・ゴーストの速さ・パワーエサの効果時間が変わり、ハイスコアは難易度ごとに保存されます

  | 難易度 | 残機 | ゴーストの速さ | パワーエサ |
  | --- | --- | --- | --- |
  | EASY | 5 | ×0.85 | 10 秒 |
  | NORMAL | 3 | ×1.00 | 8 秒 |
  | HARD | 2 | ×1.12 | 5 秒 |

- パワーエサでゴーストがイジケ状態になり、食べると 200 → 400 → 800 → 1600 点のコンボ得点（得点はその場にポップアップ表示）
- エサを 70 個・170 個食べるとフルーツが出現（レベルに応じて種類と得点が変化）
- 10000 点で 1UP（残機 +1）
- レベルが上がるとゴーストが速くなりイジケ時間が短縮。全エサ回収時は迷路が点滅してクリア演出

## 実装のポイント

- 28×31 タイルの迷路を Canvas 上に描画。迷路はオフスクリーンにキャッシュし、devicePixelRatio に合わせた高解像度描画
- Blinky・Pinky・Inky・Clyde がそれぞれ異なるターゲットタイルを狙う追跡ロジック。散開/追跡の時間切り替え、ワープトンネルでの減速、残りエサが少なくなると Blinky が加速（Elroy）
- 曲がり角を少し通り過ぎた直後の入力でも、角に戻って曲がれるコーナリング猶予（0.3 マス）
- 1/120 秒の固定タイムステップでゲームロジックを更新（リフレッシュレートに依存しない挙動）
- 左右のワープ通路で端にまたがるキャラは反対側にも描画し、途切れない
- 盤面は画面の高さに合わせて自動フィットし、スマホでもスクロール不要
- タブが非表示になる、またはウィンドウがフォーカスを失うと自動ポーズ。ハイスコアとミュート設定は localStorage に保存（使えない環境でも動作）

## 遊ぶには

`index.html` をブラウザで開くだけで動作します。GitHub Pages を有効化すれば、そのままブラウザからプレイできます。

## 自動テスト

`tests.html` をブラウザで開く（GitHub Pages 上、またはローカルサーバー経由）と、25 項目のテストが走り、結果が一覧表示されます（ページタイトルにも PASS / FAIL が出ます）。迷路の全エサが到達可能か・ゴーストが固まらないか・コーナリング猶予・ゴースト撃破とコンボ得点・フルーツ・1UP・ゲームオーバー・レベルクリア・ゲームパッド・30 分相当のランダムプレイなどを検証します。

コマンドラインからは `bash run-tests.sh`（ヘッドレス Chrome を使用。`CHROME=/path/to/chrome` で指定可）で実行でき、失敗すると終了コード 1 になります。GitHub Actions（`.github/workflows/tests.yml`）が push / PR ごとに同じテストを実行します。

仕組み：URL に `#test` を付けて `index.html` を開くと、ゲームループを止めて `window.__pacman` からゲーム内部（状態・`tick(秒)` など）を決定的に操作できます。通常のプレイ時には公開されません。

## その他の対応

- ゲームパッド（十字キー / 左スティックで移動、A・Start でスタート/ポーズ）
- OS の「視覚効果を減らす」設定では、迷路・パワーエサ・イジケ終了の点滅を抑制
